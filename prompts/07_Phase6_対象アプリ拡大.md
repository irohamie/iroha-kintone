# Phase 6：対象アプリの段階的拡大

## 事前にまーくんへ確認すること

1. 「今回追加したいアプリのIDを教えてください（一度に5アプリ程度まで）」
2. 「対象アプリで自動化ユーザー `GitHub連携（自動）` に
   アプリ管理権限を付与し、『アプリを更新』まで済んでいますか」

権限付与が未了の場合、以下をボタン単位で案内する（各アプリで実施）。

1. kintoneのポータル画面から対象アプリを開く
2. 画面右上の歯車マーク（アプリの設定）をタップ
3. 「設定」タブをタップ
4. 「アクセス権」の欄にある「アプリ」をタップ
5. 「ユーザー／組織／グループを追加」の欄で `GitHub連携（自動）` を検索して選択
6. その行の「アプリ管理」のチェックボックスをオンにする
7. レコード閲覧・追加・編集・削除、ファイル読み込み・書き出しは**すべてオフのまま**にする
8. 画面右下の「保存」をタップ
9. 画面右上の「アプリを更新」ボタンをタップ
10. 確認ダイアログで「更新」をタップ

【重要】手順9を忘れると権限が反映されません。全アプリで実施してもらうこと。

## あなたがやること

1. `config/apps.json` の該当アプリの `enabled` を `false` から `true` に変更する
2. `node scripts/02_list_apps.js` を実行し、フォルダ名が自動生成されることを確認する
3. `node scripts/03_pull_all.js` を実行する
4. `node scripts/08_pull_app_settings.js` を実行する
5. 以下を**あなた自身が検証する**
   - 各JSファイルの末尾が正しく閉じているか（`tail -3`）
   - `node --check` が全JSファイルで成功するか
   - `manifest.json` の `size` と `wc -c` が一致するか
   - `settings/fields.json` が取得できているか
6. 結果を「アプリID／アプリ名／ファイル数／総バイト数／構文チェック／フィールド数／成否」
   の表形式で報告する
7. 取得に失敗したアプリは原因を特定して報告する
   - 403 → 権限付与漏れまたは「アプリを更新」忘れ
   - ファイル0件 → URL指定方式の可能性。manifest の `url` を確認して `note` に記録
8. コミット・push
   メッセージ：`Phase 6：対象アプリ拡大（App{ID列挙}を追加）`
9. `CLAUDE.md` 9章の進捗表を更新してコミット

【禁止】全アプリを一度に `enabled: true` にすること（原因切り分けが困難になる）
【禁止】権限付与の確認をせずに実行を進めること
